# CanvasGuard

A behavioural trust layer for Canvas LMS API integrations.

Built in response to the May 2026 Instructure breach.
Open-source. Institution-deployable. Work in progress.

→ Read the full thesis: builtbyanwar.github.io/canvasguard

## The problem
Canvas API trust model asks one question: is this credential valid?
It should be asking five. This project is about building those five questions.
